## Como usar

1. Abre o **ROADMAP.md** da disciplina — indica a ordem de estudo e ligações aos módulos.
2. Estuda cada ficheiro em `modulos/` por ordem.
3. Faz os **exercícios** no fim de cada módulo antes de ver as **soluções**.
4. Consulta **materia-extra.md** para aprofundar além do programa.

## Estrutura por disciplina

```
disciplina/
├── ROADMAP.md          # Percurso de conhecimentos
├── materia-extra.md    # Tópicos complementares recomendados
└── modulos/            # Um ficheiro por tema, com exercícios + soluções
```

## Nota sobre IA

Algumas disciplinas têm políticas diferentes sobre IA na avaliação. Usa estes materiais como apoio ao estudo; na avaliação segue sempre as regras oficiais de cada UC.
